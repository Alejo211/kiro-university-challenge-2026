# horoscopo-cli Steering

- This project is a Node.js CLI tool called horoscopo-cli

- Always use ES modules (import/export), never CommonJS (require)

- Use commander.js for CLI argument parsing

- Use chalk for terminal colors

- Horoscope phrases must be funny and in Spanish

- File structure: src/index.js, src/signs.js, src/horoscope.js

- package.json must have "type": "module" and a "bin" entry

- Keep code minimal, no unnecessary comments
